# 一盏

一个无框架、无构建步骤的网页泡茶交互原型。项目使用 Canvas 2D 绘制画面，通过 Web Audio 合成声音并循环播放背景音乐；用户可以拈取草药、提壶注水，并等待茶汤和茶签生成。

在线体验：<https://guopanqi.github.io/tea-2d/>

## 启动

项目使用原生 ES Module，需要通过 HTTP 静态服务器访问。运行下面的命令会启动服务器并自动打开浏览器：

```bash
cd /Users/usr/Documents/play/tea-2d
./run
```

默认端口是 `8080`，也可以用 `./run 3000` 指定端口。脚本依赖 macOS 已自带的 Python 3。

电脑浏览器打开：

```text
http://localhost:8080
```

在终端按 `Ctrl+C` 停止服务器。

## 手机局域网访问

1. 确保手机和电脑连接同一个 Wi-Fi。
2. 在 Mac 上查询局域网 IP：

   ```bash
   ipconfig getifaddr en0
   ```

3. 假设命令返回 `192.168.100.86`，在手机浏览器打开：

   ```text
   http://192.168.100.86:8080
   ```

如果 macOS 弹出防火墙提示，请允许 Python 接收网络连接。访问期间需要保持电脑开机，且不要退出静态服务器。

## 操作方式

- 点击右上角“百草柜”，从十味食药物质中选择最多五味放到茶盘；也可点击茶方笺快速配好茶盘。
- 按住草药拖入杯中；在草药上停驻片刻可查看介绍。
- 同一味可以反复投入，左上方笺会按 400ml 茶杯实时显示份数、演示克数、寒热倾向与超量提醒；“退一味”可撤销最近一次投放。
- 按住茶壶并拖向杯口，倾斜茶壶开始注水。
- 拈起茶匙，在有水的杯中持续画圈；水流会逐渐形成漩涡，停手后靠惯性慢慢平息。
- 杯中有草药并完成注水后，等待茶汤浸泡并生成茶签。
- 点击音符按钮可以静音。
- 茶签出现后，点击“再沏一盏”重新开始。

桌面端使用鼠标，移动端直接触摸操作。

## 项目结构

```text
.
├── index.html       # 页面入口
├── style.css        # 页面布局与界面样式
├── assets/          # 循环背景音乐等静态资源
├── js/
│   ├── main.js      # 启动、交互事件与动画主循环
│   ├── scene.js     # 背景、茶具和场景绘制
│   ├── herbs.js     # 草药绘制与状态
│   ├── water.js     # 水位、水流和茶色效果
│   ├── steam.js     # 热气效果
│   ├── brew.js      # 配方、混色与茶名生成
│   ├── label.js     # 茶签
│   └── audio.js     # Web Audio 音效
├── DESIGN.md        # 设计方案
└── TODO.md          # 后续迭代记录
```

项目不依赖 npm 包，也不需要后端服务。部署时可直接发布到任意静态网站托管服务。
